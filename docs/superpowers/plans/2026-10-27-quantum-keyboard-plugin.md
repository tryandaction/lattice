# 量子键盘官方插件实施计划

**Goal:** 实现可见、可发现、无需记忆的高效公式输入官方插件。
**Architecture:** 插件拥有生命周期和延迟加载界面，复用统一输入与键位持久化，目录与展示分离。
**Tech Stack:** React 19、Next.js 16、Zustand、KaTeX、MathLive、CodeMirror 6、Vitest。
**Spec:** docs/superpowers/specs/2026-10-27-quantum-keyboard-plugin-design.md

## 约束

只开发量子键盘，不改版本、发布、提交或分支；不覆盖其他窗口改动；兼容现有自定义键位；不默认映射普通输入；候选完整、窄屏可用。

## 执行

- [x] 目录与查询：测试中文/英文/命令搜索、完整候选、用户覆盖、预览占位符与分类。
- [x] 生命周期：测试官方注册、命令和停用；实现 manifest、runtime、host 与兼容出口。
- [x] 界面：以 QWERTY 多含义键帽为主界面，辅助搜索、收藏和最近；流动彩色外框、完整候选、桌面无裁切、窄屏可达，底部说明紧凑化。
- [x] 编辑器：排除面板输入目标、保护 MathLive 编辑状态，验证双 Tab、占位符和连续输入。
- [x] 设置：官方插件名称、说明、配置入口，清除旧原生快捷键误导。
- [x] 验证：29 个文件 314 项回归、类型检查和相关 lint 通过；最终浏览器 24 组界面与 10 步生命周期检查通过。
- [x] 更新指南、定稿设计和插件收尾交接记录。

## 2026-10-28 收尾

用户确认 UI 定稿，本轮仅收束插件稳定性和交接。补查源码模式下无消费端输入队列、双 Tab 重复键/IME/修饰键、公式编辑焦点转移、跨编辑器候选、映射切换与块级公式保存等边界，并为确认的问题加入失败回归测试后修复。
