# 云端库协作收尾设计

用户授权：本窗口自主检查、设计并落实；沿用本地工作区，只增加必要云端按钮。

## 现状与选择

复用现有 CloudLibraryWorkspaceController、稳定 item/version 身份、持久化 outbox、Worker 版本 CAS、邀请成员、AI 云来源和主 PDF 阅读器。选择增量完善同一工作区；不新建独立云端编辑器，不引入实时字符协同或新的服务依赖。

## 产品行为

1. 云文件顶部轻量工具条：共享/成员、云端 AI、历史、同步反馈。共享入口复用现有邀请和角色管理。云文件继续使用本地同款标签、分栏和编辑器。
2. PDF 批注显示：全部、只看自己、只看他人、全部隐藏，并允许逐成员显示/隐藏；过滤同时作用于页面与批注列表，只影响当前用户视图，隐藏不删除、不产生同步写入。偏好按账号/连接/文件保存；写入继续使用完整批注集合和增量变更。
3. 文件历史：作者昵称、时间、版本、当前版本；查看旧文本或下载旧文件；恢复历史内容创建新版本并以当前版本为基线。存在未同步编辑、编辑草稿、版本变化时阻止直接恢复，提供清晰反馈。服务端权限保持最终裁决。
4. 云端 AI：从当前云文件或目录进入既有 AI 面板，明确当前来源；复用现有 API 模型配置、目录读取、PDF 子文件和具体提案审查流程，不自动将他人内容覆盖。AI 操作仍归当前账号、遵守角色和源版本。
5. 同步状态区分本机已保存/待同步/已同步/离线/冲突，冲突保留双方内容并可处理。协作者新版本不会静默替换未保存草稿。

## 边界与验证

历史读取检查库和条目归属、不可变版本、内容 hash 和身份切换；恢复使用现有 save/outbox/CAS，不直接修改历史记录。离线只读取已缓存历史，不伪造远端成功。批注显示偏好不作为访问权限。

按独立模块测试 → 工作区集成测试 → lint/typecheck → 浏览器桌面/窄窗口交互 → qa:gate。远程部署、数据库迁移执行、提交和推送不在本次授权范围。

实现依据：本地 Next 16.3 文档及仓库既有版本事务/CAS 协议。Context7 月度额度已用尽；官方文档在线检索适配器也不可用，未把网络请求失败记为已查阅资料。
