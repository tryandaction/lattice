# 量子键盘与 Markdown 公式输入指南

量子键盘是 Lattice 官方结构化公式输入插件。主界面就是电脑 QWERTY 键盘：每个字母键把该键的候选直接画在键帽上，用户看键帽即可输入，不需要记忆长 LaTeX 命令。选择键帽后会展开带名称的完整候选条；长整式在键帽显示简短名称，选中后查看完整排版。

## 键盘主流程

- `Tab Tab`：在编辑器打开量子键盘。插件停用时双 Tab 不会被拦截。
- 变量填写：直接按字母和数字；方向键在结构内部移动光标。
- `F2`：在“符号直输”和“变量填写”之间切换。模板（分式、根式、积分、矩阵、括号、量子态）插入后自动进入变量填写。
- 符号直输：按字母键锁定候选，再按 `1–9` 输入；也可以直接点键帽上的候选。
- 按住 `Shift` 再按字母锁定扩展层，松开 Shift 后按编号选择。
- `F3`：切换默认候选层。键帽标题选中后，方向键可浏览全部候选，`Enter` 输入，`Esc` 取消；10 项以上候选使用此方式。
- `/`：符号直输时打开查找；填写时用 `Alt + /`。输入名称或 LaTeX，`↑/↓` 选择，`Enter` 输入，`Esc` 返回实体键盘。
- `Alt + F`：填写时选择 F 键候选，再按编号嵌套分式；其他结构使用对应字母。
- `Tab` / `Shift + Tab`：前后移动公式空位。
- `Ctrl + I + 2`：二重积分；`Ctrl + I + 0`：环路积分；`Ctrl + I + 20`：二重环路积分；`Ctrl + I + 30`：三重环路积分。数字依次输入，松开 Ctrl 时插入。
- `Ctrl + M + 34`：直接输入 3×4 矩阵；单个数字如 `Ctrl + M + 3` 输入 3×3。松开 Ctrl 时插入并进入第一格。
- 矩阵编辑时，`Alt + Enter` / `Alt + →` 增加行或列。
- `Ctrl + Enter`：完成当前公式，回到 Markdown 编辑器。
- `Esc`：关闭键盘并回到之前的编辑位置。
- `F4`：打开键位设置。

键帽显示候选编号与公式排版；选中键后，候选条同时显示完整名称。例如 F 键包含分式、展示分式、导数模板等；M 键包含矩阵、μ、± 等。点击单个符号也可以插入，完整流程可以只用键盘完成。填写时 Shift 数字对应的 `^`、`!` 等标点正常输入，输入法组合输入和 AltGr 不被改写。

矩阵常用模板可在 M 键选择，键帽以括号类型和尺寸标示，例如 `(2×2)`、`[2×2]`。Ctrl 矩阵组合支持 1–9 行、1–9 列；点击矩阵候选打开尺寸输入，可指定最多 20 行、20 列。圆括号、方括号、无括号和行列式样式保留。插入后按 Tab 填写单元格。I 键包含单/双/三重、环路、闭曲面、闭体积以及定积分模板；Ctrl 积分组合一步输入常用积分类型。

## 所见即所得编辑

插入模板后，公式会在编辑器原位置用 MathLive 排版显示。分式直接在横线的上方和下方填写；矩阵直接按单元格顺序填写；根号、上下标、括号、bra-ket 和嵌套结构都保留实际渲染形态。公式编辑控件保持连接，源码同步不会重建它，因此连续输入、Tab 导航、撤销和重做不会丢失焦点或历史。

插件启用时，双击渲染后的公式会定位到同一个公式编辑层并打开量子键盘；双击 Tab 仍然可以从编辑器任意位置打开。渲染公式右键的 Markdown/LaTeX 复制菜单由 Lattice 原生渲染器提供，插件不会替换复制格式。

键盘会自动为正在编辑的公式保留可见空间，避免浮层遮挡公式。关闭或完成公式后，编辑器恢复原来的布局。

## 官方映射与我的映射

顶部可以切换“官方推荐”和“我的映射”。官方推荐是 Lattice 提供的默认层；我的映射使用设置中的可编辑名称、LaTeX 和自定义符号。修改名称或 LaTeX 后会立即反映在键帽、编号选择、搜索和插入结果中。原有自定义符号和“我的公式”库仍保留；可以给常用公式命名后按中文、英文或 LaTeX 搜索。

“查找”是辅助入口，不替代键盘主界面。搜索覆盖官方层、扩展层、自定义符号和保存的公式，点击结果同样插入当前编辑位置。

键帽内每个候选都由独立色块完整包住编号和符号。键盘保留流动彩色外框，面板随内容收紧高度；桌面窗口完整展示三行字母键和控制键，窄屏可左右滚动查看，并显示滚动提示。长公式使用简明预览或名称，悬停详情显示完整排版。

## 插件

量子键盘以 `quantum-keyboard` 官方插件运行，和公式 OCR 一样可在插件设置中启用、停用、配置和使用工具栏命令。“双 Tab 打开”开关即时生效。停用会提交正在编辑的公式、关闭面板、移除双 Tab 和输入桥接；普通编辑器输入恢复原生行为，无需刷新即可再次启用。

切换到其它编辑器会取消原位置待选的候选和未完成组合；从文档进入键盘控制再返回原文档，可以继续选择。Source 模式和普通文本输入目标保存源码；“我的公式”中的块级公式编辑或改名后仍保持块级格式。
