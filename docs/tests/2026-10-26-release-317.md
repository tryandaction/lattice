## 修复内容

- 批注提案提交前重新读取请求页并绑定当前 PDF 版本；不会因为上一轮阅读账本不在当前工具会话中而误报“未读取”，也不会默默接受版本变化。
- 引文校验支持同页连续读取片段和重叠片段，保留真实 PDF 连字；必须形成完整页的连续实际覆盖，并且在同页唯一匹配。错误页、未读间隔、冲突片段、改写引文和过期版本继续拒绝。
- API Agent 对 `page_not_read`、`quote_not_found`、`ambiguous_quote` 只做一次、同一 PDF 同一步骤的安全修复；不能借恢复计划生成另一份 PDF 或重复批注提案。权限、版本、参数和结构错误直接失败。
- 批注工具返回真实 `verifiedSourceRead` 后，正文证据账本能够识别“先提案、后核验”的有效读取；`pending-review` 仍不等于已保存。
- PDF 阅读器等待批注持久化成功后才清理 `_annotations.md` 草稿；保存失败、关闭期间中断或清理失败都会保留草稿以便重试。批准后的批注通过现有文件变更事件即时导入已打开 PDF。
- API 规划和本地 Harness 共用按实际暴露工具筛选的 Lattice 产品操作说明，覆盖来源读取、PDF 批注、PDF 子文件、Markdown/Notebook 提案和云库资源版本边界。生产云端部署没有虚构成可执行工具。
- “全文已分析但回答只使用相关摘录”与“仍有页面未读”现在分开显示；证据缺口仍会保留提示。
