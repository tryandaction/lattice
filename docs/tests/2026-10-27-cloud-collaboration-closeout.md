# 云端库架构与协作功能收尾

日期：2026-10-27。用户授权本窗口完成云端功能；明确暂不更新桌面产品，由其他窗口统一交付。

## 已落实的用户流程

- 继续使用现有本地工作区布局、文件树、标签、分栏和各类编辑器。云文件增加同步状态、共享与成员、云端 AI、版本历史；窄分栏使用紧凑图标。
- PDF 支持全部、仅自己、仅他人、全部隐藏及逐成员勾选；页面、批注列表和带批注导出保持一致。偏好按连接/账号/文件在本机保存，同文件分栏同步，跨版本保留。隐藏不删除共享内容，也不等于访问权限。
- 版本历史展示作者、时间、版本、恢复来源；文本可预览和逐行比较，二进制可下载历史原文件。恢复创建新的不可变内容版本，不覆盖或删除历史。
- 协作者更新显示加载最新版本；编辑草稿不被静默覆盖。恢复前检查所有同源分栏的草稿、待同步队列、冲突及当前版本，读取期间的新编辑会取消恢复。取消信号进入 IndexedDB 事务；提交前可原子回滚，提交后按真实成功返回。
- 云文件/目录一键进入原 AI 面板；来源用文件名标签显示，问题框及用户消息不暴露内部来源编号。保留既有问题草稿，不自动提交。内部身份、权限范围和版本仍随原始草稿保存，切换账号及在途账号切换会阻止重新绑定。
- AI 使用用户已有 API 模型或本机工具配置，不创建团队共享密钥或新的托管推理服务。共享写入沿用具体提案审查、当前账号归属和现有权限检查。

## 架构与数据保护

复用 `CloudLibraryWorkspaceController`、持久化 outbox、源 provider、既有 Worker/Edge API 与数据库 RLS/CAS。无新增依赖、数据库迁移或服务端路由；版本恢复来源记录在现有 manifest。

历史读取重新验证成员和条目归属，核验不可变版本及内容 SHA-256；离线只允许已缓存历史预览。恢复联网重查权限和当前基线，提交仍使用服务器原子版本比较；冲突保留本地内容。

补正远端批注列表覆盖本地嵌套 mutation/在途更新的问题、共享乐观批注账号隔离、AI 批注成员归属、规范化投影确认、同步重开后的 AI 撤销，以及共享入口刷新期间切库的竞态。普通阅读不再自动把预览补全写回云端。

这是版本同步与冲突处理式共创，未引入实时多人光标/逐字符合并。PDF 批注保持与原始文件版本绑定，不自动把几何迁移到另一份 PDF。
