3. 左栏末段到右栏首段，正/反方向选择；PDF 内容流故意按行交错排列。
4. 跨页正/反向选择；包含浏览器原生 Range 为空或折叠在错误端点的情况。
5. 按住鼠标时滚动页面，再完成跨页选择；核对文字、保存文件、重开后的高亮位置。
6. 公式保存后重开；核对整块高亮高度与保存的归一化矩形一致。
7. 保存失败、无本地 OCR、公式语法错误、不可信数学命令与公式源位置改变。
