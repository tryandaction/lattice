## 本轮修复

- 批注工具契约和运行时共用样式规则：受支持的颜色名、三位和六位十六进制按原 CSS 含义规范化；不将非法类型或透明/动态颜色默认为有效高亮。
- 一批建议中的可恢复引文问题按项处理，有效草稿保留供审查。全部无效、源版本冲突和结构非法仍明确失败；通过数、排除数和部分完成状态进入工具记录与对话正文。
- 重复 AI 批注 ID 幂等跳过，用户编辑后的已有批注保持原样，新建议继续保存；撤销仅涉及此次实际新增项。
- PDF 批注的公式显示从当前页真实字形重建；旧文本批注不必具备 LaTeX 元数据。矩阵整体高亮，分式按完整数学行绘制下划线，独立页面栏不串连，分离的公式编号不进入公式包围框。
- 稀疏矩阵先识别成对高括号，再分离页面栏；重复公式必须有明确上下文或几何定位，不能默认取第一个。唯一原文匹配允许旧 DOM 上下文排版差异，公式原文匹配避免被可读文本转换改写。
- PDF 证据统一断行连字符校验。补证只允许同来源、同页的新核验发现修复对应缺口，保留已验证发现和未修复的问题。
- Agent 已通过批注工具交付草稿时，以实际执行回执、PDF 来源版本和草稿内容确认交付，不再要求最终回答重复输出另一份批注 JSON。模型口头声称成功、失败工具或无关来源回执不能通过；用户另要求的 Markdown 正文仍须提供。
