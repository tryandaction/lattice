# 3.1.8 PDF 批注与矩阵交付记录

日期：2026-10-26。针对用户反馈的自动批注向后多选、公式高亮碎片和矩阵结构识别问题。本轮只使用合成材料和离线模型桩，没有调用真实模型或读取用户论文。

## 行为变更

- `passageId/quoteId` 可以配合经过原文核验的较短 `quote` 选择精确子范围，不再强制回填完整证据窗口，从而把后续解释句一起高亮。越界、改写、非唯一引文继续拒绝。
- 全文自动批注默认上限固定为 5 条，用户显式设置可以覆盖；提示要求选择最小完整论点，不填满配额，也不选择孤立矩阵行。
- 公式高亮显示为同一个公式区域的整体包围矩形；下划线按视觉行分别合并。临时选择预览和已保存批注共用几何逻辑。
- 确切匹配的 AI 批注在落地时使用当前页的真实文本/字形几何进行公式结构识别。只有可确定的公式才增加公式元数据；普通段落和不确定布局不会被强行猜成公式。
- 结构解析从硬编码 2×2 扩展到几何明确的矩形矩阵，包括 2×3、3×3。每行须存在一致且唯一的列边界；空单元、不规则或歧义布局保留待核对状态，不猜补符号。
