# 2026-10-13 活动 PDF 与真实 Agent 工具链修复

## 实际故障

用户在 Senoo PDF 阅读界面询问“Z2-ordered Greenberger–Horne–Zeilinger (GHZ) states是什么思想”，Agent 却称当前文件为 `research/current-note.md`。排查确认该路径来自后端硬编码默认值；前端把无“本文”或文件名的术语问题路由成 general，丢掉当前 PDF。规划器又没有收到真实 pathIdentity，缺读后最后一次补充计划未执行，最终在空材料上生成答案。

## 修复

普通术语问句保留活动文件身份和请求级授权，Chat 与 Agent 均可按需调用真实来源工具，不默认阅读全文、不扫描无关工作区。明确独立问题仍不读当前文件，真正的历史追问保持原论文。无文件路径时保留用户提供的文字，但不编造路径、当前文件标签或文件引用。

独立复核补充了同名概念笔记反例：当前论文旁即使存在 `GHZ.md`，普通“分析/比较 GHZ”及带引号术语也不作为新文件标题扫描。共享命名意图判断保留明确“阅读 Study”和“两篇论文比较”。最后6组来源与真实浏览器回归272项通过；独立定位/绑定复核129项通过。

规划器获得真实来源身份与可执行工具；选定文件缺少正文时必须完成有效读取才进入回答。最后一次补充规划仍会执行其中的工具，预算只限制再规划次数。自动全局索引摘要不会混入受限来源的答案。正常首次单文件任务保留“初始规划→读取后观察规划→回答”，以允许模型依据原文决定追加相关页面，约3次模型请求。

桌面目录列表用已有 `desktop_file_metadata` 获取大小与修改时间，避免为列出文件名搬运整篇 PDF。超出读取字节预算的文件在传输正文前拒绝；实际回答仍读取正文并计算内容版本。

模型响应保留不含正文的诊断：协议、内容块类型、可见字符数、停止原因、用量。修正 Responses 用量字段，规划器不再丢失模型元数据。空回答恢复尊重用户配置与模型上限，答案续写共用连接配置的总截止时间；用户停止或超时保留已收到正文。不记录或显示隐藏推理文本。

独立复核修复了流结束后清理阶段挂起仍阻塞取消的边界：`iterator.return()` 同样受截止时间和用户停止控制，并保留草稿。规划阶段的空输出诊断也写入安全trace，不仅保存最终答案阶段的信息。
