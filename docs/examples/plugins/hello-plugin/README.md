# Hello Plugin (Example)

This folder is a ready-to-install example plugin package.

## Install
- Settings -> Extensions
- Click "Import directory" and choose this folder. If directory selection is
  unavailable, ZIP the contents (manifest.json at the archive root) and use
  "Install ZIP".

## Verify
- Enable the plugin runtime under Advanced plugin settings if it is disabled.
- Open Details, review the requested permissions, and trust the plugin.
- Enable the plugin and confirm that its status is Running.
- Run "Hello Demo: Say Hello" in the plugin's Details section or Command Center.
- Open Command Center (Ctrl+K) and run "Hello Demo: Say Hello"
- Open Plugin Panels (Ctrl+Shift+P) and open "Hello Panel" or "Hello Panel (Runtime)"
