# Lattice v3.0.0 发布验收目标

目标：五条核心科研体验路径均完成修复和验收后，再生成本地 `releases/v3.0.0` 产品包。版本号变更不代表产品通过验收。

| 方向 | 必须达到的行为 | 验证证据 |
| --- | --- | --- |
| AI 来源定位 | 仅在具体论断旁显示针对性引文，不将读取过的页面自动列为引用；每条引用绑定可核验原文或现成精确锚点；跨PDF/Markdown切换真实文件并将对应原文置于可见区域，用局部红色虚线框示意；无唯一原文时明确未定位，不用整页或模糊片段冒充成功 | 从page/file-only上下文生成少量原文引用；真实PaneWrapper跨PDF→MD→PDF往返；真实Huie论文；文件身份、逐行文字Range、red/dashed计算样式和overflow裁剪检查 |
| 科研工作流 | 用户能选择流程、了解输入/产物、修改笔记语言/风格/章节/引文/模板；配置传入 runner 并持久化；默认值可恢复；无未实现执行的虚假成功 | Store/UI/runner 集成测试；设置与刷新恢复；恢复竞态测试 |
| PDF 阅读批注 | 选文复制与高亮文本/几何一致；批注保存恢复；搜索、来源、缩放及文件切换不被旧异步请求抢回；无效页拒绝 | PDF 聚焦测试；真实论文浏览器回归；隔离新桌面二进制 smoke |
| Markdown | 阅读/实时预览/源码路径继续可用；数学异步加载不重挂载图片和代码；特殊格式、链接和本地截图回归不退化 | Markdown renderer/live preview/表格/公式/链接测试；浏览器交互 |
| HTML/网页与代码 | 工作区本地 HTML 图片/CSS 正常；网页抓取失败仍有隔离预览和浏览器入口；编辑器/Notebook 跳转和性能基线通过 | HTML resource/网页刷新测试；主工作区真实 HTML 预览；代码/Notebook 导航与性能回归 |

统一出口：`npm run qa:gate` 全部成功；新桌面二进制版本为 3.0.0；测试配置与正在运行的安装版隔离；打包脚本拒绝旧二进制/近似版本安装包；manifest、文件大小和 SHA256 与产物一致。

2026-09-20 用户追加的 PDF 发布阻断：同一段文字的鼠标拖选预览、点击高亮后的持久显示、前后边界拖动并恢复原范围后的显示，必须使用一致的文本范围与逐行几何；在比例字体、跨行、双栏、缩放和重新打开后均应成立。诊断页的硬编码测试覆盖层不能充当这项验证。必须有直接比对三条真实路径的回归与可视证据。

每项按复现、根因、最小修复、回归测试、实际交互和独立审阅推进。缺陷与例外记录在 `docs/superpowers/plans/2026-09-18-v3-research-workbench.md`。产品更新仅指用户指定的本地发布包，远程部署和覆盖当前安装版不在本次范围内。

真实边界：当前不提供定时 AI 执行；HTML 预览禁用脚本，复杂打包网页及 CSS import/srcset 链路不宣称完全支持；外部网站可拒绝 iframe；确定性 AI 测试不等于所有真实模型供应商可用；跨机器安装需独立环境验收。
